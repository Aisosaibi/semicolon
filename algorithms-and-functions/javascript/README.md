# JavaScript collections

- `prompt-for-user-age.js` and `print-hello-and-thank-you.js` are standalone
  input and greeting exercises; their original names are recorded in the
  source comments.
- [`introductory-exercises/`](./introductory-exercises/) contains the welcome
  exercise set, still organized by its original `Task...` identifiers.
- Related cohort submissions and their tests live under
  [`../phase-gate/I/`](../phase-gate/I/), grouped by project, day, and language.

Use source comments and tests to recover the full prompt where a filename is
only an assignment identifier.

No matching tests were found for the standalone files or the introductory
exercise set. Phase Gate has tests for some assignments, but not every
submission; the known syntax failures and test gaps are listed in
[`../unsolved/javascript/`](../unsolved/javascript/).
