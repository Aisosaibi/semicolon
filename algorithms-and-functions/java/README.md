# Java collections

The folders below use descriptive names. Java class and file names are kept
where they are required to match public class names or existing tests.

| Collection | Contents |
|---|---|
| `array-basics/` | Array concatenation, reversal, and largest-element exercises |
| `delivery-wage-calculator/` | Rider delivery-pay calculation and tests |
| `number-base-converter/` | Number-base conversion |
| `introductory-exercises/` | Basic numeric, date, sorting, and classifier exercises |
| `chapter-four-exercises/` | Textbook-style chapter four exercises |
| `rainbow-color-exercise/` | Map a color choice to a rainbow color |
| `basic-output-exercises/` | Console output and simple variable-formatting exercises |
| `array-method-exercises-4/` | Array methods including filtering, searching, sorting, and prefix sums |
| `array-index-and-sum-exercises/` | Select array elements by index and sum selected values |
| `loop-and-input-exercises/` | Repeated input, totals, and averages |
| `geometry-and-conversion-exercises/` | Geometry calculations and unit conversion |
| `java-weekend-projects/` | The four Java weekend-project applications and acceptance checks |
| `loop-exercises/` | Counting, divisibility, and arithmetic loops |
| `basic-arithmetic-exercises/` | Small arithmetic, output, and shape-printing exercises |
| `kata-solutions/` | Kata solutions |
| `number-guessing-game/` | Number-guessing console application |
| `pizza-calculator/` | Pizza pricing exercise |
| `promo-and-pizza-exercises/` | Promotion engine, tests, and pizza pricing |
| `regular-expression-validation/` | Regular-expression validation project |

Individual `Task...` files retain their original assignment identifiers;
their source comments and neighboring tests provide the inferred prompt.

## Test coverage

Test or acceptance-check projects are present in
`delivery-wage-calculator/`, `number-base-converter/`,
`java-weekend-projects/`, `promo-and-pizza-exercises/`, and
`regular-expression-validation/`. The remaining standalone collections do not
have an obvious matching test suite in their collection and are flagged in
[`../unsolved/java/`](../unsolved/java/).
