# Python collections

- [`algorithm/`](./algorithm/) contains standalone algorithm exercises. The
  Code Wars pyramid-level sum problem is documented and tested there.
  `find_missing_values.py` is an incomplete exercise currently tracked in the
  unsolved queue.
- [`introductory-exercises/`](./introductory-exercises/) contains numeric,
  date, sorting, and classifier exercises.
- [`basic-arithmetic-exercises/`](./basic-arithmetic-exercises/) contains
  introductory arithmetic, output, and shape-printing tasks.
- [`chapter-exercises/`](./chapter-exercises/) contains chapter-based textbook
  exercises.
- `class-work/` contains JSON file reading and writing practice, along with
  its local project/environment configuration.

Problems in the Phase Gate exam are organized separately under
[`../phase-gate/I/`](../phase-gate/I/), where language folders and nearby tests
are kept together.

The `algorithm/` collection has tests, including a currently failing test for
`finding_nemo.py`. No matching tests were found in the other standalone
exercise collections; see [`../unsolved/python/`](../unsolved/python/) for the
syntax failures and review items.
